# ComplainEase – Digital Complaint Management System

## About the Project

ComplainEase is a simple web application developed to make complaint management easier in colleges, hostels, and other institutions. Instead of handling complaints manually, users can submit their issues through the website and track their status.

The project provides separate views for students and administrators, making it easier to manage complaints and update their progress.

## Features

- Student registration and login interface
- Raise complaints by selecting a category
- View submitted complaints and their current status
- Admin dashboard to view and manage complaints
- Update complaint status to Open, In Progress, or Resolved
- Simple and responsive user interface
- Browser-based data storage using LocalStorage

## Technologies Used

- HTML – Page structure
- CSS – Styling and responsive design
- JavaScript – Application functionality
- LocalStorage – Storing demo data in the browser

## Complaint Categories

- Academic
- Hostel
- Infrastructure
- Maintenance
- Other

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Register or log in to explore the application.
5. Use the admin view to check complaints and update their status.

## Project Limitations

This is a frontend-based academic project. Complaint data is stored in the browser using LocalStorage, so it is not shared between different browsers or devices. A backend and database can be added in the future to support real users and centralized complaint management.

## Future Improvements

- Integrate a database for permanent complaint storage
- Implement secure user authentication
- Add email notifications for status updates
- Include complaint search and filtering
- Improve the admin dashboard with reports and analytics

## Purpose

This project was developed as part of an Object-Oriented Software Engineering (OOSE) course to understand how a complaint management system can be designed and implemented using basic web technologies.
